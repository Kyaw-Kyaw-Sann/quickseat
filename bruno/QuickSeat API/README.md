# QuickSeat Bruno Collection

Open the `QuickSeat API` folder in Bruno, then select the `Local` environment.

Set only the variables you obtain during testing:

- `baseUrl` (defaults to `http://localhost:8080/api/v1`)
- `customerToken`
- `adminToken`
- `staffToken`
- `bookingReference`
- `ticketToken`

The collection deliberately contains no real credentials, JWTs, database values, or email secrets. The requests cover the main public, auth, customer, admin, and staff groups. Use [API_Documentation.md](../../API_Documentation.md) for the complete endpoint list and request/response examples.
